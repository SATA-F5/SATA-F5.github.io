# 守禄の收藏夹 · File 目录说明

本目录不再需要导入脚本。`site3.html` 打开时会实时读取仓库的 GitHub 文件树，
把这里的音频 / 视频自动列出来；新增文件推送到仓库后就会出现在页面上。

- 收录大小：838.9 MB
- 快照时间：2026-11-07 08:42

## 目录

- `bilibili/` — B 站收藏（音频、封面、少量视频）
- `music/` — 本地音乐
- `videos/` — 本地视频
- `manifest.js` — 离线快照，读不到 GitHub API 时兜底（不需要手动编辑）

## 新增文件

1. 把音频 / 视频放进 `bilibili/`、`music/` 或 `videos/`
2. 提交并推送
3. 打开页面就会自动收录，无需修改 HTML，也无需运行脚本

页面右上角的刷新按钮可以立即重新扫描，不必等缓存过期。

## 封面

- 约定：封面文件名是 `<视频名>_cover.jpg`，和视频放在同一目录
- 视频没有封面时，页面会在浏览器里截取视频首帧作为封面
- 仓库里已有的视频封面均由首帧生成（720px 宽 JPEG）

## 去重

- 文件名带 `(1)`、`(2)` 这类副本后缀的会被忽略，不会收录
- 之前误传的 `默言 - Everywhere We Go（remix）(1).mp3`、`202607271833(1).mp4` 已删除

## 收录规则

- GitHub Pages 单站约 1 GB、单文件 100 MB，超大文件不要放进仓库
- 音频：mp3 / wav / flac / m4a / ogg / aac / opus
- 视频：mp4 / mkv / mov / webm / avi
- 站点统计口径：`counts.music` 含 B 站音频，`counts.video` 含 B 站视频

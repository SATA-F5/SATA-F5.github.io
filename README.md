# 守禄的 Win11

这是一个把个人主页做成 **Windows 11 桌面** 的网页。打开链接就是一块桌面，
不再是看一个静态页面，而是坐在一台"电脑"前：双击图标开窗口、用里面的
浏览器上网、在"此电脑"里翻文件夹，甚至能找到作者藏起来的小彩蛋。

在线体验：<https://sata-f5.github.io/>

## 里面有什么

- **假桌面**：可以拖动、缩放、最小化、最大化的窗口，底部是任务栏、开始菜单和系统托盘。
- **开机自检**：首次打开先走一遍 AMI BIOS 自检 + Win11 启动动画（约 2.8 秒），用 localStorage 记住后刷新不再重播；任务栏右侧有重启/关机按钮。
- **假 Edge 浏览器**：双击桌面图标打开，支持多标签、地址栏搜索、后退/前进/刷新，能直接嵌入部分网站，被拒绝嵌入的会提示用真实浏览器打开。
- **此电脑**：一套虚拟文件系统，有 C:/D: 盘和桌面、文档、下载等文件夹，点面包屑可以一层层来回跳，文本文件能直接预览。
- **信息面板**：侧滑可以看到快捷方式、正在打开的窗口，还有模拟的 CPU/内存/磁盘占用。
- **明暗主题**：任务栏里一键切换，下次打开记得你的选择。

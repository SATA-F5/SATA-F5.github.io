# 守禄的 Win11

这是一个把个人主页做成 **Windows 11 桌面** 的网页。打开链接就是一块桌面，
不再是看一个静态页面，而是坐在一台"电脑"前：双击图标开窗口、用里面的
浏览器上网、在"此电脑"里翻文件夹，甚至能找到作者藏起来的小彩蛋。

在线体验：<https://sata-f5.github.io/>

## 里面有什么

- **启动器**：打开网址先看到启动页，点「启动桌面」后**在当前页播 BIOS 自检动画**，同时后台预加载桌面；动画结束时桌面已就绪，直接开新标签页进入锁屏，不再重复播放开机动画。桌面是脚本打开的，所以「关机」能真正关闭它。
- **假桌面**：可以拖动、缩放、最小化、最大化的窗口，底部是任务栏、开始菜单和系统托盘。
- **锁屏与登录**：进入桌面先看到 Win11 风格锁屏（大时钟 + 日期 + 右下角网络/辅助功能/关机），点击或按任意键切到登录页，输入任意 PIN 回车即可进入；头像和图标使用微软官方 Fluent UI 图标。
- **任务栏**：开始按钮靠左，右侧是一排应用图标，运行中的程序下方有指示条；悬停窗口的最大化按钮会弹出贴靠布局（左右分屏 / 四象限）。
- **设置应用**：开始菜单里的「设置」是 Win11 风格窗口，含 系统 / 个性化 / 网络 / 账户 / Windows 更新 等页面，可切换明暗主题、查看设备规格与磁盘占用。
- **所有应用 / 任务视图**：开始菜单可切到按字母分组的全部应用列表；任务栏第二个按钮打开任务视图，卡片式切换或关闭窗口。
- **通知中心**：点击右下角时钟打开日历，上方是通知列表（系统提示会自动收录，可一键清除），有关闭时时钟右上角显示小圆点。
- **Win+X 与显示桌面**：右键开始按钮弹出快捷菜单（设置、文件资源管理器、关机等），任务栏最右侧细条可一键最小化所有窗口。
- **自绘壁纸**：Bloom 风格的花瓣由浏览器实时渲染（SVG 渐变 + 高斯模糊），不依赖任何外部图片，也没有水印。
- **开机自检**：首次打开先走一遍 AMI BIOS 自检（2 秒）+ Win11 启动动画（约 2.5 秒），用 localStorage 记住后刷新不再重播；开始菜单底部有重启/关机按钮。
- **假 Edge 浏览器**：双击桌面图标打开，支持多标签、地址栏搜索、后退/前进/刷新，能直接嵌入部分网站，被拒绝嵌入的会提示用真实浏览器打开。
- **此电脑**：一套虚拟文件系统，有 C:/D: 盘和桌面、文档、下载等文件夹，点面包屑可以一层层来回跳，文本文件能直接预览。
- **明暗主题**：任务栏里一键切换，会同步到桌面、窗口和所有本地页面（site1/site2/site4），下次打开记得你的选择。
- **Win11 图标**：此电脑、Microsoft Edge 等桌面/任务栏图标为自绘的 Win11 风格图标，不依赖外部图片。

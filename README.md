# 守禄的 Win11

这是一个把个人主页做成 **Windows 11 桌面** 的网页。打开链接就是一块桌面，
不再是看一个静态页面，而是坐在一台"电脑"前：双击图标开窗口、用里面的
浏览器上网、在"此电脑"里翻文件夹，甚至能找到作者藏起来的小彩蛋。

在线体验：<https://sata-f5.github.io/>

## 里面有什么

- **假桌面**：可以拖动、缩放、最小化、最大化的窗口，底部是任务栏、开始菜单和系统托盘。
- **锁屏与登录**：进入桌面先看到 Win11 风格锁屏（大时钟 + 日期 + 右下角网络/辅助功能/关机），点击或按任意键切到渐变磨砂玻璃登录卡片，点「登录」即可进入；头像和图标使用微软官方 Fluent UI 图标。
- **任务栏**：开始按钮靠左，任务栏只显示当前打开的窗口（一个窗口一个按钮），活动窗口点击最小化、再点还原；悬停窗口的最大化按钮会弹出贴靠布局（左右分屏 / 四象限）。
- **设置应用**：开始菜单里的「设置」是 Win11 风格窗口，含 系统 / 个性化 / 网络 / 账户 / Windows 更新 等页面，可切换明暗主题、查看设备规格与磁盘占用。
- **所有应用 / 任务视图**：开始菜单可切到按字母分组的全部应用列表；在桌面（或左边缘）向右滑即可打开任务视图，卡片式切换或关闭窗口。
- **通知中心**：点击右下角时钟打开日历，上方是通知列表（系统提示会自动收录，可一键清除），有关闭时时钟右上角显示小圆点。
- **Win+X 与显示桌面**：右键开始按钮弹出快捷菜单（设置、文件资源管理器、关机等），任务栏最右侧细条可一键最小化所有窗口。
- **自绘壁纸**：默认 Bloom 风格的花瓣由浏览器实时渲染（SVG 渐变 + 高斯模糊），不依赖任何外部图片，也没有水印。
- **壁纸切换**：设置 → 个性化 → 背景里内置 6 款壁纸（默认 Bloom、Bloom 浅色/深色、日出、流、光晕），点击即时生效并记住选择。
- **开机自检**：首次打开先走一遍 AMI BIOS 自检（4 秒）+ Win11 启动动画（约 2.5 秒），用 localStorage 记住后刷新不再重播；开始菜单底部有重启/关机按钮。
- **关机画面**：纯黑背景 + 居中的 GK ASCII 艺术字，点任意处或电源键重新开机。
- **假 Edge 浏览器**：双击桌面图标打开，支持多标签、地址栏搜索、后退/前进/刷新，能直接嵌入部分网站，被拒绝嵌入的会提示用真实浏览器打开。
- **独立应用窗口**：桌面上的 MCAC、EasyTier Go、收藏夹、工具箱等本地页面各自作为独立程序打开，标题栏图标直接使用各自的 `siteN.png`；页面里的外链会交给假 Edge，当作默认浏览器处理。
- **快速设置**：任务栏右下角打开，六枚磁贴（WLAN / 蓝牙 / VPN / 飞行模式 / 专注助手 / 辅助功能）+ 亮度、音量滑块 + 电池栏；状态与「设置 → 网络 / 系统」双向同步并记住。
- **经典应用**：开始菜单 → 所有应用里可以找到记事本（自动保存）、计算器（支持键盘）、画图（保存 PNG）、命令提示符（常用命令）和任务管理器（Win11 进程页，右键结束任务）；图标全部取自 Win11 图标包。
- **此电脑**：一套虚拟文件系统，有 C:/D: 盘和桌面、文档、下载等文件夹，点面包屑可以一层层来回跳，文本文件能直接预览；工具栏可新建文件夹，右键文件/文件夹可重命名、删除。
- **桌面右键**：刷新、切换图标大小（大/中/小）、按名称或类型排序、直接打开显示设置 / 个性化。
- **明暗主题**：任务栏里一键切换，会同步到桌面、窗口和所有本地页面（site1/site2/site3/site4），下次打开记得你的选择。
- **守禄の收藏夹**：`site3.html` 是一个本地媒体收藏页，收录 B 站音频/视频、本地音乐与视频，支持搜索、筛选、排序、随机打开、底部音乐播放器和视频弹窗。资源放在 `File/` 目录下，页面实时读取 GitHub 文件树，新增文件推送后自动出现；视频封面取首帧，缺封面时浏览器端即时截帧兜底。
- **Win11 图标**：此电脑、Microsoft Edge 等桌面/任务栏图标为自绘的 Win11 风格图标；文件管理器、文件夹与文件类型图标来自 Public Domain 的 Windows 11 Icon Set（`assets/icons/`）。
